# AI-powered product search and price comparison assistant based on Kimi

This project introduces an advanced search and comparison system leveraging large-scale text generation models. Designed to interact seamlessly with users, the system delves into their specific requirements and preferences to deliver tailored product search results. Additionally, it facilitates product comparisons, aiding users in identifying the best value-for-money options.

### Key Features

1. **User-Centric Interaction**:
   - Engages in dialogue with users to understand their needs and preferences.
   - Provides personalized product search results based on user input.
2. **Product Comparison**:
   - Conducts detailed comparisons of products.
   - Assists users in selecting the most cost-effective options.
3. **Advanced Model Integration**:
   - Built on the Kimi large model developed by Moonshot Inc.
   - Utilizes the OpenAI API library with the model variant moonshot-v1-8k.
4. **Specialized Assistants**:
   - Implements three distinct assistants, each based on a unique preset prompt.
   - Each assistant is tailored to perform specific functions related to search and comparison tasks.

### Usage

1. **Engage with the System**:
   - Start a dialogue to specify your product needs and preferences.
2. **Receive Tailored Results**:
   - Get personalized product recommendations based on your inputs.
3. **Compare Products**:
   - Use the system to compare different products and identify the best options.
